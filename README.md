# AI Usage Analysis Among Students

Mini-project for Velammal Engineering College, CSE.

## Stack
- Frontend: React + Vite + CSS
- Backend: Python + Flask
- Database: SQLite
- Charts: Recharts

## Visual upgrade
The frontend now includes a dark futuristic AI interface with:
- CSS 3D AI neural core
- Animated orbital rings
- Floating 3D cubes
- Rotating pyramid and ring objects
- Pulsing neural nodes
- Glowing AI scene labels
- Animated gradient CTA buttons
- Hover/tap transitions and page entrance animations
- Animated score bars
- Responsive mobile layout
- Reduced-motion support

The 3D scene is built from CSS/DOM elements, so no heavy 3D library is required for the visual layer.

## Run
### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

The frontend defaults to `http://127.0.0.1:5000` for the Flask API. For online deployment, set `VITE_API_URL` to the deployed backend URL.
